Ubah konten, foto, logo, dan data produk dari HP atau komputer. Website tetap menggunakan GitHub Pages.

Token hanya digunakan selama tab ini terbuka. Muat ulang atau keluar untuk menghapus sesi. Jangan gunakan komputer bersama.

Pertama kali masuk? Ikuti panduan ini
  1. Masuk ke GitHub dengan akun tokokurdimotor.
  2. Buka pembuatan fine-grained token ↗. Beri nama “Admin Kurdi Motor” dan masa berlaku, misalnya 30 hari.
  3. Pilih Only select repositories, lalu tokokurdimotor.github.io.
  4. Di Repository permissions, atur Contents → Read and write. Metadata tetap Read-only. Izin lain tidak diperlukan.
  5. Tekan Generate token. Salin ke kolom di atas. Simpan salinannya di pengelola kata sandi pribadi; jangan kirim lewat chat.

Halaman panel dapat dibuka siapa saja. Perubahan hanya dapat disimpan dengan izin GitHub yang sah. Ini login memakai token GitHub, bukan kata sandi toko.
